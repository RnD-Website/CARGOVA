# Fonts

The reference uses **Departure Mono** (pixel mono, display/UI) and **GT Pressura** (body).

- Departure Mono is free (SIL OFL) — download it from https://departuremono.com and place
  `DepartureMono-Regular.woff2` in this folder. `src/css/base.css` already loads it from here.
- GT Pressura is a commercial typeface (Grilli Type). If you hold a licence, add its
  `@font-face` in `src/css/base.css`; otherwise the site falls back to Archivo.

Until the files are added, the site uses Space Mono + Archivo from Google Fonts.
