## Units travelling the conveyor
order (wire cube) → parcel → palletised crate → shipping container → CARGOVA-branded container.
This mirrors the reference's units changing form at each station.

## Responsive
- ≤991px: sidebar hidden, full-width `start dispatch` button under the spec box, station boxes dock to the bottom at full width, and the camera reframes so the machine sits in the upper half.
- ≤767px: pill nav swaps to a mobile menu, community buttons become icon-only, type scale steps down.
